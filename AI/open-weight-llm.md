# 主要なオープンウェイトの LLM について

LLM には、API 経由でしか使えない「クローズド」なものと、モデルの重み（パラメータ）が公開されている「オープンウェイト」なものがある。
今回は **オープンウェイト LLM** について、代表的なものと合わせてまとめてみた。

## オープンウェイトとは？

**オープンウェイト（open weight）** とは、学習済みモデルの**重み（パラメータ）が公開されていて、誰でもダウンロードして使える**こと。

- 自分の PC やサーバー上で動かせる（ローカル実行）
- ファインチューニング（追加学習）でカスタマイズできる
- API の利用料がかからない（自前の計算資源は必要）

### 「オープンウェイト」と「オープンソース」は違う

混同しやすいが、厳密には別物。

| 用語 | 公開されるもの |
| ---- | -------------- |
| オープンソース | 学習コード・学習データ・重み など、再現に必要なもの全部 |
| オープンウェイト | **重みのみ**（学習データやコードは非公開のことが多い） |

> 「Llama はオープンソース」と言われることもあるが、学習データは非公開なので、正確には「オープンウェイト」に近い。
> またライセンスで商用利用に制限がある場合もあるので、利用前に確認が必要。

## クローズドモデルとの違い

| 観点 | オープンウェイト | クローズド（API 提供） |
| ---- | ---------------- | ---------------------- |
| 重みの入手 | 可能 | 不可 |
| 実行環境 | ローカル / 自前サーバー | 提供元のクラウド |
| カスタマイズ | ファインチューニング可能 | 基本不可（制限あり） |
| コスト | 計算資源が必要 | 従量課金（トークン単位） |
| データの扱い | 外部に出さず完結できる | 提供元に送信される |
| 代表例 | Llama, Mistral, Gemma, Qwen | GPT, Claude, Gemini |

> ※ Claude（Anthropic）や GPT-4 系、Gemini などは重みが公開されていないクローズドモデル。

## 主要なオープンウェイト LLM

### Llama（Meta）

- Meta が公開しているオープンウェイト LLM の代表格
- オープンウェイト界隈のデファクトスタンダード的存在で、派生モデルや日本語追加学習モデルも多数

### Mistral / Mixtral（Mistral AI）

- フランスの Mistral AI が公開
- 小型ながら高性能なモデルで知られる
- Mixtral は前にメモした [MoE（Mixture of Experts）](moe.md) を採用したモデル

### Gemma（Google）

- Google が公開している軽量なオープンウェイトモデル
- クローズドな Gemini とは別物（Gemini はオープンウェイトではない）

### Qwen（Alibaba）

- 中国の Alibaba が公開
- 多言語対応や幅広いサイズ展開が特徴

### DeepSeek（DeepSeek AI）

- 中国の DeepSeek が公開
- MoE を活用した大規模モデルや、推論特化モデルで注目された

### その他

- **Phi（Microsoft）**：小型でも高性能を狙った「SLM（小規模言語モデル）」
- **Command R（Cohere）**：RAG 用途を意識したモデル
- **gpt-oss（OpenAI）**：OpenAI が公開したオープンウェイトモデル

## オープンウェイトを使うメリット・注意点

### メリット

- **データを外部に出さずに済む**（プライバシー・機密保持）
- **API 料金が不要**でランニングコストを抑えられる
- **自由にカスタマイズ**できる

### 注意点

- **動かすには相応のマシンスペック（特に GPU / メモリ）が必要**
- モデルごとに**ライセンスや商用利用の条件**が異なる
- 最新の超大規模クローズドモデルと比べると、性能で劣る場合もある

## まとめ

- オープンウェイト = **重みが公開されていてローカルで動かせる** LLM
- 「オープンソース」とは厳密には別物（重みのみ公開が多い）
- 代表例は **Llama / Mistral / Gemma / Qwen / DeepSeek** など
- データを手元に置ける・カスタマイズできるのが強みだが、計算資源とライセンス確認は必要

用途や扱うデータの機密性によって、クローズドとオープンウェイトを使い分けるのが大事だと感じた。
